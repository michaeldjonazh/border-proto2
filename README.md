# BORDER｜国境をひく

全日本AIハッカソン2026 決勝の練習用プロトタイプ。テーマ「境界」。

架空の世界の地図に国境線を1本引くと、衝突メーターと、国境の両側の住民の声（架空の言語＋日本語訳）が出る。

## 動かし方

`index.html` をブラウザで開くだけ。外部ライブラリなし（Google Fontsのみ）。

- 地図をドラッグして、端から端まで線を1本引く（端に届かなくても自動で延長される）
- 「この国境で判定」を押す
- 「縦の線」「斜めの線」「でたらめな線」で、すばやく試せる

## 仕様（現状）

| 項目 | 内容 |
|---|---|
| 地図 | 12×8マス、型は直線国境型のみ |
| 属性 | 4つ：地形・川・資源・言語 |
| 言語 | 2つ（架空。世界ごとに語彙が変わる） |
| 判定 | 言語分断／水利権／内陸国／資源偏在／長い国境／無主地 |

## 現状はダミー

判定の文章と声は、ルールで組み立てたダミー。AIには繋いでいない。

`index.html` の `fakeAI()` が差し替えポイント。本番では `/api/claude`（Vercel関数 → Anthropic API、モデルはHaiku）を呼ぶ形にする。APIキーはVercelの環境変数 `ANTHROPIC_API_KEY` に置き、フロントやリポジトリには出さない。

## 検証

```
node tests/logic-check.js
```

世界生成・線による分割・判定・声の組み立てを検証する（Node.jsのみ。依存なし）。

## 構成

```
index.html              画面とロジック（LOGIC_ENDより上がDOM非依存のロジック）
tests/logic-check.js    ロジックの検証スクリプト
```

## デプロイ

Vercelにそのまま載せられる（静的ページ）。AIを繋ぐときは `api/claude.js` を追加する。
